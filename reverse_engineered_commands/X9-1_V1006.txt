## Requesting all camera settings per workmode (think of this as a tree with primary and secondary menu items)

### This request returns primary menu items for the set workmode and their current settings
/cgi-bin/hi3510/getprimarymenuitem.cgi?-workmode=NormalPhoto
Line-based text data: text/plain (1 lines)
    var item="Resolution,Lens angle,Exposure,ISO,White balance,Time stamp,Scene mode";var cur="12M,Medium,AUTO,AUTO,AUTO,Off,Auto";\r\n

### Using the following request, all of the options of a specific primary menu item of a specified workmode can be returned, as well as the one currently set. it would be best to have a command like settings-tree that would show all settings
/cgi-bin/hi3510/getsecondmenuitem.cgi?-workmode=NormalPhoto&-name=Lens%20angle
Line-based text data: text/plain (2 lines)
    var item="Wide,Medium,Narrow";\r\n
    var value="Medium";\r\n

### A set command for the secondary menu item. It would be great if it could dynamically return/allow the options as they can vary between models.
/cgi-bin/hi3510/setcurparameter.cgi?-workmode=NormalPhoto&-name=Lens%20angle&-value=Narrow
